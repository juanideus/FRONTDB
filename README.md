## Herramientas necesarias
Se necesita
- Node
- Visual Studio Code

## Para instalar
Se debe de seguir el siguiente orden

```bash
git clone https://github.com/FranciscoConcha/FrontBaseDeDatos.git
```

```bash
npm install
```

## Para configurarlo a tu manera.
Se debe de actualizar el archivo que config_api donde tiene las url del backend
y en cada servicio ver las url final de lo backend, además de adaptar las interfaces necesarias.
